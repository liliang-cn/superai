## 本轮修复

1. 对同一监控智能体的重复报告做汇总，避免几十条旧告警淹没待处理列表；完整历史仍可进入智能体查看。
2. 人工处理项支持定位具体智能体和编程运行，而不是仅打开总览。
3. 日程页面展示个人日历记录；相同时间与参会人的重复会议不重复展示，保留原始数据。
4. 补齐核心界面的中文标签和主题面板翻译。
5. 通知中心打开期间可持续刷新；避免在 React 状态更新函数内执行标记已读的副作用，只标记当前显示的通知；增加错误反馈和键盘操作。
6. 修复 MCP 添加入口的等待反馈。
7. 提醒的“今天 / 明天”判断按日历日期计算，避免夏令时切换误判；无效时间不输出 Invalid Date。
8. 编程输入补充原生 input / composition 同步；编辑区域明确排除原生窗口拖拽。
9. 按用户要求移除编程页底部智能体按钮，改为输入框内下拉；新增常驻状态栏。
10. 取消部分输出时增加明确的已停止提示；状态栏监听取消事件。
11. 长会话标题单行省略，完整内容可通过悬停查看。

## 范围限制与剩余观察

- Windows、Intel Mac、其它 macOS 版本未在本轮实际运行。
- 删除真实看板 / 智能体、安装外部技能 / MCP、改变凭据、安全权限、发送真实邮件和 webhook 未操作；相关后台逻辑由现有 Go 测试覆盖到的部分通过。
- printf 测试走了允许的只读路径，不能据此声称本轮人工操作了所有审批 / 拒绝分支；人工按钮渲染和后台权限测试均有自动覆盖。
- 用户报告的“无法输入”未稳定复现。实测能完成英文键入和中英文粘贴，并做了输入事件防御修复；真实中文输入法候选词流程没有完整自动操作。
- MCP 注册表中的远程服务安装入口仍有限：部分项提示按 URL 添加，但当前列表只支持可执行启动命令。这是现有功能缺口。
- 旧页面部分长说明、状态文本和时间轴标签仍使用英文，语言切换不代表全应用翻译已完整。
- Hive guardian 仍在报告已缩容的 worker-3～9 缺失，需要校正监控职责 / 笔记里的旧集群预期。前端汇总解决重复展示，不会自动断言这些告警已处理。
- 查询得到的日程中曾存在同一会议的两个名字；本轮仅去重显示，没有删除数据。
